Smart Lost & Found Management Portal

About the Project

The Smart Lost & Found Management Portal is a web-based application designed to help users report lost and found items across campus and other locations. It helps people find their belongings through organized reports and smart matching.

Features

* Report lost items
* Report found items
* View and manage item reports
* Smart matching of lost and found items
* Claims portal for item recovery
* Responsive user interface

Technologies Used

* HTML
* CSS
* JavaScript
* Supabase (database and backend services)

Project Structure

* index.html – Main page
* login.html – Login page
* css/ – Stylesheets
* js/ – JavaScript files
* supabase/ – Database schema and configuration

How to Run

1. Download or clone this repository.
2. Open index.html in a web browser.
3. Configure Supabase if required for backend features.
